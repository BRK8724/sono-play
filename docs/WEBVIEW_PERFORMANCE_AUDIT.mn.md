## 2026-11-18 adaptive quality follow-up

Gameplay starts at DPR <=1.25 and keeps Phaser synchronized to the browser's native `requestAnimationFrame` cadence. A fixed-buffer rolling frame monitor evaluates gameplay intervals in 2.5-second windows. The four profiles are high (DPR 1.5), balanced (1.25), economy (1.0), and low (1.0 plus fewer effects). After two unhealthy windows, it lowers DPR/effects; six healthy windows can restore one quality step. It does not impose a 30 or 60 FPS timer cap: the device/browser controls presentation cadence. This avoids Phaser's timer-based FPS limiter introducing uneven intervals on variable-refresh displays. Fixed 60 Hz physics, collision geometry, server config, score, and reward state are unchanged. The selected gameplay background is loaded after player state is known; Santa/Gold textures load only when selected. Initial preload keeps Pilot, split pipe shaft/cap sprites, and default day art. Physical device profiling remains pending.

The source pipe sheet was 633×2116 (about 502 KB); gameplay now loads only its 366×327 shaft and 448×204 cap crops (about 233 KB total). Their decoded pixel count is about 84% lower than decoding the entire sheet. The separate source sheet remains in `public/` for artwork history but is excluded from the runtime manifest. Bird frames remain separate because the supplied poses are individual files and must retain their alpha/art quality; a combined atlas export is still a designer/build-pipeline follow-up.

The supplied 128×128, 7.5 KB `santa sono.webp` is now the default Pilot game sprite and Store thumbnail. Its measured visible bounds are 128×119 alpha pixels and it is scaled to 54.2×52.8 CSS pixels to match the prior Pilot silhouette. The four legacy 490×501 body/wing textures and old 1173×1207 Pilot thumbnail are no longer runtime assets, saving about 3.7 MiB of decoded gameplay textures plus their transfer size. This single default sprite has no flap-pose artwork, so the default character no longer animates its wing; motion/physics remain intact. Supply matching poses/atlas to restore that visual animation.
